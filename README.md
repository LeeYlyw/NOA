# NOA

게임은 `Assets/1.Scenes/MapGeneration_Test.unity`에서 실행합니다 (`offlineMode = false`).
로컬 서버가 없으면 게임이 `GameServer.exe`를 창 없이 실행하고 로비에 접속합니다.
같은 실행 파일을 두 번 실행하면 같은 로비에 접속합니다. 플레이어별로 따로 빌드할 필요가 없습니다.
서버가 먼저 접속한 클라이언트에 Player 1, 다음 클라이언트에 Player 2를 배정합니다.
번호 수신 전에는 직업 선택·준비·게임 패킷 전송을 대기하며, 조작 캐릭터·카메라·UI도 배정된 번호에 맞춰 연결됩니다.
직업은 접속 순서와 관계없이 로비에서 선택합니다.
각자 직업을 선택하고 준비를 누르면 방장이 게임을 시작할 수 있습니다 (현재 정원 2명).
직업을 바꾸면 준비가 취소됩니다. 시작 후 기존 맵 생성과 스폰이 실행됩니다.

서버 코드를 변경한 뒤에는 `Server/GameServer/GameServer.vcxproj`를 x64 Debug로 빌드합니다.
Windows x64 게임 빌드 시 서버 실행 파일은 게임 폴더의 `Server/GameServer.exe`로 자동 복사됩니다.
배포 시 이 Server 폴더도 함께 전달해야 합니다. 현재 Debug 서버는 Visual C++ 개발 런타임이 필요합니다.
서버를 별도로 수동 실행할 필요는 없습니다. 기존 서버가 실행 중이면 새 코드로 재시작해야 합니다.
다른 PC에서 접속할 때는 해당 클라이언트의 `serverIP`를 서버 PC의 주소로 지정합니다.
로비에서 방장이 나가면 남은 플레이어에게 방장 권한이 넘어갑니다.
게임 진행 중 연결이 끊어지면 게임을 다시 실행합니다. 빈 로컬 로비 서버는 30초 후 종료됩니다.
로비 UI는 우선 기능 확인용 영어 기본 화면으로 구성되어 있습니다.

개발 환경에서 MSPDB140.DLL 버전 오류가 발생하면 서버 빌드 명령 전에 PowerShell에서 `$env:_LINK_ = "/DEBUG:NONE /INCREMENTAL:NO"`를 설정하여 디버그 심볼 없이 빌드할 수 있습니다.
