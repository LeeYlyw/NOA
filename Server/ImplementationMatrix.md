# 10월 28일 시연 구현 점검 — 서버 × 클라이언트

기준: 2026-10-25 `codex/demo-flow-p0` 코드. `[x]`는 **코드가 존재함**을 뜻하며 Unity 화면이나 실제 두 PC 통과를 뜻하지 않는다. `[ ] 구현`은 코드 보강이 남은 항목, `[ ] 확인`은 코드는 있으나 실행 확인이 남은 항목이다. `V0`은 시연 전 필수 확인, `P1`은 시연 흐름 결함이 나타나면 우선 수정, `P2`는 이후 보강이다.

범위: 두 명이 한 스테이지를 완주한다. 4개 직업/외형은 4인 동시접속 요구가 아니다. 도플갱어는 이번 범위에서 제외했고, 별도 탈출 단계는 결정되지 않았다. 애니메이션 클립·Animator Controller는 팀원 담당이다.

## 남은 구현의 권장 순서

1. **V0 즉시 확인:** 맵 생성 실패의 즉시 양쪽 안내, 아이템 목록 불일치·거리 거절·재시도는 코드와 로컬 소켓 검사를 마쳤다. Unity 화면과 실제 두 PC에서 확인한다.
2. **V0 시연 흐름 확인:** Unity 화면과 실제 두 PC의 한 판 완주. 문/몬스터 이동, 미믹 교차 피격, 텔레포트, 아이템 획득 시 시점 튐이 재현되면 해당 결함을 먼저 수정한다.
3. **P2 화면·콘텐츠:** 로비/결과 `OnGUI` 통일, 결과 연출, 필수 아이템 구역별 위치 규칙과 단서 정식 에셋을 차례로 보강한다. 발판→잠긴 방 경로 안내와 단계별 문양 표시는 코드에 반영했다.
4. **P2 서버 신뢰 경계:** 아이템 배치·획득 위치 대조와 일반 이동 검증은 기본 아이템 사용/몬스터 AI의 재구현과 구별해 진행한다.

## 검증 기준과 다음 행동

- **자동 완료:** C# 컴파일 오류 0개, C++ Release 빌드, 로컬 두 소켓의 맵 실패·아이템 목록 불일치·종류/거리 거절·내비게이션·몬스터 공격/치유·미믹 교차 피격 및 3라운드 퍼즐 smoke가 기록돼 있다.
- **Unity/두 PC 미완료:** Unity 배치 실행은 LicensingClient IPC 시간 초과(코드 199)였다. 실제 화면과 두 PC 확인 결과를 임의로 완료 표시하지 않는다.
- **첫 순서:** Unity 실행 가능 환경에서 V0 항목을 확인한다. 실패가 나오면 해당 영역의 P1을 먼저 고친다. 서버 아이템 신뢰 경계와 미믹 차단은 이미 끝낸 기본 획득/동기화 작업과 구별한다.
