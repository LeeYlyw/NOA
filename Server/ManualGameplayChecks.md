표시 규칙: [x] 코드/자동 확인 완료, [ ] 실제 화면 또는 두 PC 미확인. 이전 테스트 통과를 이번 수정의 통과로 옮겨 적지 않는다. 새 클라이언트 빌드를 양쪽에 사용한다. 서버 코드는 이번 작업에서 변경하지 않았다.

## 이번 구현 / 자동 확인
- [x] 멀티 공격 번호별 재생에 더해, 정지 공격의 모션이 서버 준비 시간 종료 직후 끊기지 않도록 현재 재생 상태를 확인한다. 추적 이동 재개 시 이동 상태가 우선한다.
- [x] 오프라인 몬스터 1·2 반복 공격도 기존 MonsterAttack 상태를 재생한다. 공격 상태를 벗어나면 이전 피해 예약을 취소한다.
- [x] 비트리거 몸통 Collider가 없는 몬스터만 NavMeshAgent 크기 기준 런타임 캡슐 추가. 기존 Collider 보존.
- [x] 이름/메시에 barrel이 포함된 방 소품 중 몸통 Collider가 없는 메시만 런타임 BoxCollider 추가. 이후 NavMesh 생성에 포함. 박스 근사이므로 모서리 걸림 실측 필요.
- [x] 로컬 카메라의 몸 중심→카메라 위치 사이 SphereCast로 벽 앞 위치 제한. 자기 Collider와 Trigger 제외, 프레임별 배열 할당 없음. 근접 클리핑 평면 최대 0.05m.
- [x] C# 빌드: 경고 13개, 오류 0개. 프리팹/모델/Animator/씬 파일은 이번 작업에서 수정하지 않음.

## P0 — 멀티 두 PC에서 먼저
- [ ] 몬스터 1·2 각각 제자리에서 5회 연속 공격 받기: 첫 회뿐 아니라 매번 모션이 보이고 양쪽 HP가 일치한다. 공격 준비→피해 순서 확인. 정확한 손 접촉 프레임은 아직 맞췄다고 보장하지 않음.
- [ ] 공격 준비 중 사거리 밖/벽 뒤로 빠지기: 피한 공격이 뒤늦게 맞지 않는다. 재접근 때 새 공격 모션부터 시작한다.
- [ ] 각자 몬스터의 정면/옆/뒤로 밀기: 몸통 통과가 줄었는지 확인. 서버 몬스터가 플레이어 쪽으로 이동할 때 겹침/밀림도 확인. 런타임 Collider는 서버의 플레이어 회피까지 구현한 것이 아님.
- [ ] 드럼통 모든 방향에 걷기/달리기: 통과하지 않고, 상자 근사 경계에 과도하게 걸리지 않는다. 몬스터가 드럼통을 관통하거나 통로에서 멈추지 않는다.
- [ ] 맵 5회 재시작: 몬스터가 벽/가구에 끼지 않고, 맵 준비 실패 없이 양쪽이 같은 맵에 진입한다. 실패 시 콘솔 Seed 기록.
- [ ] 일반 문과 퍼즐 문: 양쪽 개폐 일치, 열린 문 통과, 닫힌 문 통과 불가, 몬스터가 닫힌 문 너머로 공격하지 않음.

## P1 — 직업 1~4, 오프라인 먼저 + 멀티 동료 화면
- [ ] 벽/문/드럼통에 밀착한 상태에서 좌우 회전·위아래 보기·달리기·웅크리기: 벽 뒤 노출, 갑작스러운 카메라 튐, 자기 몸 노출 없음. 모서리/낮은 천장도 확인. 카메라 시작점 자체가 벽 안인 경우는 별도 결함으로 기록.
- [ ] 직업 3 발 높이: 평지에서 정지/걷기/달리기/점프/웅크리기를 본인·동료 화면으로 확인. 바닥에 박히거나 떠 있으면 직업·동작·화면 캡처 기록. 시각 메시/리그 오프셋 원인은 확인 전 임의 보정하지 않음.
- [ ] 문·복도 벽 겹침: 방별 문을 열고 실제 통과. 겹치거나 막히면 Seed와 해당 방 전체 화면 기록. 프리팹 경계와 생성 배치 중 원인을 구분해야 하므로 이번에는 벽을 임의 제거하지 않음.
- [ ] 탐색자만 단서를 보고 획득, 감지자는 소리로 찾기, 치유자/러너는 단서 실물 비표시. 감지자 사망/클리어 후 경고음 중단.
- [ ] 텔레포트: 동료 한쪽이 벽일 때 빈 쪽 이동; 사방 막힘/천장 낮음이면 미소비; 직업별 바닥 높이 유지.
- [ ] 오프라인 공격: 연속 5회 모션, 준비 중 도망갔다 재접근해도 즉시 과거 피해가 들어오지 않음.
